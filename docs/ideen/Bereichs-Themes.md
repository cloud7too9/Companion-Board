## Ausgangslage

Auf dem Dashboard soll man an der Gestaltung sofort erkennen, aus welchem Bereich ein Widget stammt. Jedes Widget übernimmt das Theme seines Bereichs.

## Festgelegt

| Bereich | Theme |
| --- | --- |
| Karte | Dynamisch nach Dimension: Die angezeigte Dimension (Oberwelt, Nether, End) bestimmt das Theme. Sonderfall, weil es wechselt statt fest zu sein. |
| Handbuch | Rahmen wie ein aufgeschlagenes Buch, der Inhalt steht auf der Seite |
| Baupläne | Blauer Bauplan-Hintergrund mit weißem Gitternetz |
| Portal-Verwaltung | Schwarz-lila, weder Rot noch Grün |

## Noch offen

Sammelobjekte, Banner und Rüstung haben noch kein konkretes Theme.
